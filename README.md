# 🐍 Snake Water Gun Game

## 📌 About the Project
Snake Water Gun is a simple Python-based game in which the player competes against the computer. The computer randomly selects Snake, Water, or Gun, and the winner is determined using conditional statements and game logic.

## 🎯 Objective
The objective of this project is to create an interactive command-line game that demonstrates Python programming concepts, logical thinking, and decision-making.

## 🎮 Game Rules
- **Snake vs Water:** Snake wins.
- **Water vs Gun:** Water wins.
- **Gun vs Snake:** Gun wins.
- **Same Choices:** The game ends in a draw.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Module:** Random
- **Concepts:** Dictionaries, conditional statements, user input, random selection, and f-strings.

## ⚙️ Features
- Random computer selection.
- User input for Snake, Water, or Gun.
- Automatic comparison of player and computer choices.
- Displays the result of the game.
- Simple and beginner-friendly code.

## 💻 How the Code Works
1. The `random` module randomly selects the computer's move.
2. Dictionaries map the choices to numerical values.
3. The player enters `s`, `w`, or `g`.
4. The program displays both choices.
5. Conditional statements determine whether the result is a win, loss, or draw.

## 📚 Concepts Learned
- Python dictionaries.
- Random number selection.
- Conditional statements (`if`, `elif`, and `else`).
- User input and output.
- Variables and data mapping.
- F-strings for formatted output.
